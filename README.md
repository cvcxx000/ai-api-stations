## ⚠️ 风险提示

1. 本项目仅做信息聚合，不对任何站点做背书
2. 中转站存在跑路风险，建议小额充值、分散使用
3. 数据截至 2026-10-04，站点状态可能已变化
4. 选择建议：优先运营时长 > 1年、价格透明、多源验证、可用率 > 95% 的站点
5. 涉及 API Key 的使用请注意安全，避免在不可信站点充值大额
